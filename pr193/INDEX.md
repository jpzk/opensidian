# PR #193 screenshots — Settings › Security (12 toggles + Lockdown)

Built from PR head 8212687 (feat/144-security), run on the test box (boxd display lease, harness phase 999-shots193). Each caption gives what is cut and the layer that cuts it.

1. **sec-01-security-tab-top.png**: Settings › Security at defaults (top). Lockdown switch, then Network (offline, external resources, plugin network) and Media. Defaults match develop. Values are stored once in `~/.opensidian.json` "security" and read only through `security::effective()`.
2. **sec-01-security-tab-media.png**: Defaults, middle part: Render media, WebGL, HTML canvas, MathJax/Prism. Each row says what it cuts and where.
3. **sec-01-security-tab-plugins.png**: Defaults, end of the list: Mermaid, Plugins and clipboard (spawn, plugin clipboard, app clipboard), then Engine (JavaScript JIT, needs a restart). That makes 14 rows in total.
4. **sec-02-offline-request-refused.png**: Offline mode on. A plugin's `requestUrl` is refused, and the error names "Settings › Security › Cut off all network (offline mode)". Cut in the **backend** at the `security::net_allowed` choke point. CSP keeps remote origins out of the page.
5. **sec-03-remote-image-placeholder.png**: Load external resources off. An https:// image renders as a placeholder that names the toggle. Cut in the **renderer** (no URL is emitted) and the **CSP** (`img-src`/`media-src` have no `https:`).
6. **sec-04-vault-media-placeholder.png**: Render media off. The vault png and pdf embeds show "media rendering is off (Settings › Security › Render media)". Cut in the **backend**: the `opensidian-img:` handler returns 403, and `media_read`/`pdf_info` return EPERM before any byte reaches a decoder.
7. **sec-05-graph-webgl-off.png**: WebGL off. The graph view still draws, on its 2D canvas path. Cut **natively in WebKitGTK**: `WebKitSettings::set_enable_webgl(false)`, so `getContext('webgl')` returns null.
8. **sec-06-plugin-spawn-refused.png**: Community plugins may start programs off. `spawn` is refused with an EPERM that names the toggle. Cut in the **backend** (`desk_proc_spawn`/`desk_shell` → `security::spawn_check`) before the consent dialog is shown.
9. **sec-07-clipboard-menu-paste-disabled.png**: Clipboard toggles off. In the editor context menu, Paste and Paste as plain text are disabled. Cut in the **backend** (`clip_*` commands check the calling page realm), and the **UI** greys out the rows.
10. **sec-08-mathjax-prism-mermaid-off.png**: MathJax/Prism/Mermaid off, in the editor. `loadMathJax` rejects with "MathJax is off (Settings › Security › MathJax)", and the census shows mj/pr/mm=S. Cut by the **asset hook** (`on_web_resource_request` returns 403 for `/vendor/{mathjax,prism,mermaid}/*`). The loader rejects first with the message.
11. **sec-08-math-note-engines-off.png**: The same note in reading view. Math, code and the mermaid block stay plain text because no engine bytes reach the page.
12. **sec-09-lockdown-confirm.png**: Lockdown confirm dialog. It lists what breaks and has the "Also turn off the clipboard" checkbox, plus "Turn on, restart later" and "Turn on and restart now". It is a page dialog because turning it ON only raises protections.
13. **sec-09-lockdown-on-app.png**: After the restart with lockdown on. There is a "Lockdown" pill in the status bar. The strip under the shot shows the X window title "Opensidian — Lockdown", read from X because the test display has no window manager to paint it. **Overlay** in `security::effective()` (stored values are untouched), trust wrapper, and CSP without `'wasm-unsafe-eval'`.
14. **sec-10-consent-lower-protection.png**: Lowering a protection (here: turning offline mode off). A native **GTK** consent dialog "Lower a protection…" appears, with "Keep protection" as the default and "Lower protection". Page script cannot answer it.
